# Offline fixture fonts

Latin WOFF2 subsets of the Barlow and Barlow Condensed weights already requested by `index.html`, downloaded from Google Fonts on 2026-10-13. Served only by the development fixture bridge; production assets are unchanged. These preserve app typography without external browser requests. Other Unicode glyphs use the existing system fallback.
